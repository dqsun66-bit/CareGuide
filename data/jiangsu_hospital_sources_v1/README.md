# 江苏医院来源冻结包 v1

本目录是离线构建输入，不是可直接发布的知识库。

- `sources.json` 记录抓取时间、来源 URL、HTTP 元数据和快照哈希。
- `snapshots/` 保存与哈希对应的原始官方页面。
- `review_manifest.json` 是独立复核清单，逐项绑定来源快照哈希和发布记录正文哈希，并列出正文必须命中的证据词。
- 输入来源统一标记为 `needs_review`；只有经过构建脚本的字段核对、哈希校验和人工复核后，才会在发布目录中标记为 `verified_official`。
- 构建过程不会联网，也不会把新抓取的页面自动视为已审核。
