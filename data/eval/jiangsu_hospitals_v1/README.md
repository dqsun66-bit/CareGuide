# 江苏医院知识库 BM25 评测集 v1

本评测集只验证泰州 3 家试点医院的离线、范围约束 BM25 检索，不调用大模型、华为 Embedding 或 Rerank。

- 案例数：18（每家医院 6 条）
- 正例：医院身份、院区/地址、预约或联系方式，以及常见简称表达
- 硬负例：实时车位、实时路线、医生排班、诊断与治疗建议
- 评估规则：先按声明的 `hospital_id` 和 `category` 过滤，再进行 BM25 排序
- `retrieval_cases.jsonl` SHA-256：`7c9fe0c95f40c3afdc26b67ce3421a29ef7d6bcc84eab965dc2dbf47cdde7507`

当前基线见 `bm25_baseline.json`。由于试点库每家医院每个已发布类别通常只有一条记录，当前结果主要证明范围过滤、可追溯性和拒绝无证据类别，不代表全国医院或大规模语料上的排序质量。
