满意度评价整改措施

市卫生健康委

来源：机关先锋网 时间：2024年09月18日 [ 大 中 小 ] [ 打印 ] [ 关闭 ] [ 收藏 ]

　　根据《关于2023年度市级机关单位高质量发展满意度评价意见建议反馈的通知》要求，市卫生健康委针对反馈意见建议认真分析研判、专项自查自纠、狠抓举一反三，扎实推进整改落实，具体情况如下：

　　1.  建议政策法规更倾向二孩家庭，比如医疗、教育、减少家庭养育成本，对于养育二孩的家庭，给予适当政策倾斜。

　　整改措施：一是落实完善积极生育支持措施。落实生育保险补贴，明确女职工生育二孩及三孩产假期间，分别按照企业为其实际缴纳社会保险的50%和80%给予补贴，共补贴6个月。优化生育结算标准，三级医疗机构顺产结算标准从3200元提高至4300元（助娩产5320元），剖腹产结算标准从6100元提高至6780元。改善生育二孩及以上家庭居住条件，生育二孩三孩家庭，公积金首房首贷适时调整，目前个人最高达100万元，家庭最高达130万元。二是落实托育发展经费支撑。根据《无锡市2024年“一老一幼”重点工作任务清单》要求，计划2024年新增普惠托育机构20家。我委设立无锡市普惠托育项目库，对入选普惠、示范项目的托育机构，市级财政分别给予3万元、5万元的一次性奖励，各地相应配套奖补。三是促进托育服务多元发展。积极发展社区托育服务，鼓励支持街道免费提供场地，兴建社区托育“卫星园”，惠山区长安街道和锡山区东北塘街道已建成一个中心加“N”个托育点的社区托育模式。探索园区办托，新吴区新安街道以“民办公助”的形式，建成太科城（新安）立宝托育中心，助力园区年轻父母实现带娃上班。同时，印发《关于开展促进医疗卫生机构支持托育服务发展工作的通知》，助推医育融合发展，促进托育资源向低龄延伸，提高托育机构和家庭婴幼儿科学养育和照护水平。四是构建生育友好的社会氛围。今年5月15日是第31个国际家庭日，市卫生健康委在锡山区东亭街道馨和园广场举行“无限畅‘享’‘锡’心共育”无锡市生育友好主题宣传活动启动仪式，全市首个“生育友好文化园”正式揭牌。持续通过多渠道的新型婚育文化传播方式，贴近群众生活，讲好“生育友好”的无锡故事，推动生育友好型社会的建设。

　　2. 卫健委要继续扶持无锡医院的争先进位，打造百强医院。

　　整改措施：一是系统部署谋划。印发《关于推动全市公立医院高质量发展的若干措施》《无锡市卫生健康医疗科技能力提升三年行动实施方案（2023-2025）》，实施卫生健康“办名院、建名科、增名医”战略，“一院一策”支持公立医院高质量发展。二是强化引领示范。国家消化病临床研究中心江苏分中心、国家传染病医学中心无锡基地挂牌，江苏省肺移植中心落户市人民医院，江大附院获批江苏省研究型医院建设单位，成立国家应急医学研究中心无锡分中心，江大附院成功创建为省级创伤区域医疗中心。市属医院实现“三甲”全覆盖。全市累计建成医联体31个，其中城市医疗集团5个、县域医共体6个、专科医疗联盟20个，实现了二级以上公立医院和基层医疗卫生机构全覆盖和规划区域全覆盖。三是激活内生活力。扶持推动临床专科能力建设，目前建成省级临床重点专科（建设单位）70个，市级临床重点专科113个，修订市级临床重点专科管理办法及评审标准。组织遴选临床专科重点技术33项、攻坚技术12项。四是创新体系机制。将市属公立医院考核纳入全市高质量发展综合考核体系，出台党建目标考核、绩效目标考核、重点目标考核“三位一体”的公立医院综合考核办法，考核结果与医院奖励性绩效工资总额、医院领导班子成员年薪挂钩。

　　3. 要倡导院内会诊制度，不能过分强调部门利益化。

　　整改措施：一是制定相关政策文件。印发《无锡市全面提升医疗质量三年行动计划（2023—2025年）》，在全行业开展全面提升医疗质量行动，持续深化“以病人为中心”的服务理念，提高医疗质量安全管理精细化、科学化、规范化程度，提升重大疾病诊疗能力和医疗质量安全水平，持续改善人民群众对医疗服务的满意度。二是完善质控体系建设。新增市级质控中心12个、动态调整质控中心主任12名，发布质控报告3期，调整市级质控指标，由342项增加至589项，增长72%，不断完善质控体系建设。三是加强质控培训指导。每季度召开工作例会，指导医疗机构规范开展医疗质量控制管理。强化医疗机构加强会诊制度等18项医疗核心制度培训，不断完善优化院内会诊制度、多学科讨论制度。四是建立长效监督机制。将会诊制度等18项医疗核心制度落实情况作为医疗质量与安全检查重点内容，建立长效监督机制，并将检查情况与医院年度绩效考核相结合。

　　4. 要加强和推广互联网医疗服务新模式，更好地满足百姓便捷就医需求。

　　整改措施：一是在“灵锡”APP上线医疗健康服务。统一集约式“挂缴查”入口，集成全市27家医院预约挂号功能；统一互联网医院就诊入口，15家互联网医院在线提供常见病、多发病复诊服务；增设出生医学证明查询、生育服务登记、健康档案查询、个人云影像查询、疫苗接种查询等多项线上便民服务功能。二是推动互联网医院实质化运营。加强对互联网医院规范运营的监督管理，会同市医保局积极推进互联网医院医保结算，已有11家医院在省内率先完成开通。2024年，已完成互联网医院挂号14250人次，在线咨询5922人次，就诊4688人次，处方3463笔，药品配送2369笔。市精卫中心上线“互联网+心理咨询”服务，通过互联网医院提供在线心理治疗及免费咨询。7家大型医院开展“互联网护理”，为具有居家护理需求的人群提供留置/更换导尿管护理、乳腺疏通、新生儿护理、肌肉注射等多元化服务。三是实现诊间支付及脱卡支付。会同市医保局积极推进医保移动支付，全市已有35家医疗机构实现了手机预约挂号、医保诊间支付和检查检验报告查询。市人民医院、江大附院、市中医医院和市妇幼保健院已完成微信小程序端医保脱卡支付功能，拓展了诊间支付途径。
